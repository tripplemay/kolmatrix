## Framework Learnings

- 参数化 i18n 模板如果是给 client-side 字符替换用，server 端不要走 ICU formatter，直接用 `.raw()` 取字面模板更稳。
- 角色门禁验证不能只看 HTTP 307，必须同时检查页面实际 heading / server log，才能抓到 runtime render 错误。
