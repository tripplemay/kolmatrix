## Findings

### High — contrast verification fails on non-decorative landing content

F005/F006 require contrast to meet WCAG AA. Staging Lighthouse on `/zh` produced:

```json
{
  "performance": 0.98,
  "accessibility": 0.96,
  "seo": 0.58,
  "bestPractices": 0.96,
  "lcp": 616.97,
  "cls": 0,
  "tbt": 0
}
```

The score is above the numeric threshold, but the `color-contrast` audit still fails with `score=0` and `13` flagged elements. These are not limited to decorative inactive parallax states.

Representative failures:

1. `凭经验拍脑袋，准度 50%`
2. `AI 多模态推荐，附契合度分`
3. `outgoing_mail / 邮件触达`
4. `DKIM/SPF 自配置，送达率忽高忽低`
5. `一键合规 + 信誉分 98 实时监控`
6. `Excel 拼合 3 平台导出表`
7. `实时看板 · 4 平台自动归因`
8. `六大模块`

The audit details show contrast ratios such as:

- `2.23:1`
- `3.15:1`
- `1.41:1`
- `2.46:1`

This crosses the acceptance line directly:

- spec F005: `contrast: WCAG AA`
- spec F006 L2: `a11y keyboard nav + contrast 抽样`

So this is a real blocker, not a staging-only SEO caveat and not just a pre-existing decorative parallax exception.
