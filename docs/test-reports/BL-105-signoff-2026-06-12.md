## 发现的问题（非阻断）

### 权限门控实现细节

**现象：** spec §2 称底层 server action 有 owner/admin 鉴权，但实际测试发现 `updateCampaignFieldsAction` 等仅执行租户级 RLS（`requireSession` + Prisma RLS）。

**根因：** 既有 6 个孤儿 action（BL-066 删组件后遗留）设计时仅做租户级保护，无 per-user owner/admin 强制校验。

**当前实装：** owner/admin 限制在 UI/页面层（`canEditCampaign` 门控）：
- `/edit` 页 server-side 检查 `canEditCampaign` → 非 owner/admin redirect 或 notFound
- DetailPage AcceptedKolsPanel inline 操作按钮 UI 门控 `!canEdit` 不渲染

**评估：** 
- ✅ **本批次验收范围：** UI 门控有效，L2 测试已验证权限页面工作正确
- ⚠️ **长期建议：** 若需 server 端强制 owner/admin，需单独 action 契约变更（超出本批 scope）
