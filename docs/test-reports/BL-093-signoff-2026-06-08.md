## 变更背景

Prod 故障：所有 haiku-4.5 Action 调用失败（"详细解释暂时不可用"）。根因：aigcgateway runner 从不带 max_tokens 转发上游，上游按模型 cap（haiku-4.5=64000）预留额度 → 余额 $39.56 只够 afford 55108 < 64000 → 请求预检直接拒（0.3s/$0/error）。Blast radius = 全线 haiku-4.5 Action。实际输出仅 ~4.5K，64000 严重过度配置。

修法（B2 方案）：aigcgateway `/actions/run` 路由接受 max_tokens → runner 透传上游；kolmatrix `runAigcAction` wrapper 加 maxTokens 默认 8192 + EXPLAIN_DETAILED 显式 16000。一处默认覆盖全 8 调用点。

> 注：prod 故障已靠上游 provider 充值解除；本批治本防复发。
