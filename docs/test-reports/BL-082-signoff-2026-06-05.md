## 变更背景

BL-082 的目标是把 BL-059 删除掉的 daily refresh phase 接回 `kol-sync-daily`，恢复 tiered refresh，让旧 KOL 的 follower/engagement 等字段不再完全依赖 discover 顺带保鲜。

这次修复包含三块：

1. 为全平台持久化 `platform_user_id`
2. 重接 `discover -> import -> refresh -> import`
3. 对 404 skip 做审计，并把 `refreshCount` 从硬编码 `0` 改成真实计数
