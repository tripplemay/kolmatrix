## 根因定位

定位到测试桩失真：

- 文件：`tests/unit/kol-sync-daily.test.ts`
- helper：`makeRefreshPrisma()`

问题点：

- `scripts/kol-sync-daily.ts` 的 refresh phase 先执行：
  - `deps.prisma.tenant.findUnique({ where: { slug } })`
- 但测试桩里：
  - `tenant.findUnique = async () => null`

结果：

- `runDaily()` 中 `if (tenant) { ... refresh ... }` 整段直接跳过
- 所以：
  - `fetchTieredRefreshIds()` 根本没机会拿到 mock 行
  - `dispatcher.runRefresh()` 不会执行
  - `report.refreshCount` 保持 `0`
  - refresh failure case 也不会产生 `report.errors`

这不是 Reviewer 本机环境问题，而是 BL-082 新增测试没有随着 `runDaily()` 的 tenant lookup 依赖一起更新。
