### SSH 加 env var pm2 reload --update-env 不重读 env_file（v0.9.24 #10）

#### 反例

#### 根因

4. `pm2 reload kolmatrix --update-env` 自动 carry over

#### 验证

#### F006b. §"Schema migration ROLLBACK 不对称风险"（#16 主写）

```markdown
## §X Schema migration ROLLBACK 不对称风险（v0.9.24 #16，扩展 BL-070 #22）

### 反例
BL-076-F001 `ALTER COLUMN engagement_rate TYPE NUMERIC(5,2)→(7,2)` 顺向无损（5,2 ⊂ 7,2），但 ROLLBACK `(7,2)→(5,2)` 因 prod 已含 15 行 > 999.99 → throw "value out of range"。

### 模板
扩范围 migration 的 ROLLBACK 必带 UPDATE clamp 前置 step：
```sql
-- 顺向 (无损):
ALTER TABLE "kol" ALTER COLUMN "engagement_rate" TYPE NUMERIC(7, 2);

-- ROLLBACK (非对称, prod 已含 > 999.99 行时必须先 UPDATE clamp):
-- 1. UPDATE "kol" SET "engagement_rate" = LEAST("engagement_rate", 999.99) WHERE "engagement_rate" > 999.99;
-- 2. ALTER TABLE "kol" ALTER COLUMN "engagement_rate" TYPE NUMERIC(5, 2);
```

### 适用边界
